## 代表项目

- **[Hermes Agent Workbench](https://github.com/StarrySea1412/hermes-agent-workbench)** — 基于 Hermes 的本地 Agent 工作台，整合会话、工具调用与文档操作，为特定受控工具提供审批、取消与超时处理。
- **[Easel · 二次开发](https://github.com/StarrySea1412/Easel)** — 基于 [ZJU-REAL/Easel](https://github.com/ZJU-REAL/Easel)，个人改动聚焦执行回执、会话状态隔离与网关恢复；保留 Apache-2.0 上游署名。
- **[Hermes Watch](https://github.com/StarrySea1412/hermes-watch)** — 服务器巡检与运维工作台，串联采集、规则、告警、拨测与受控执行，模型可补充诊断说明。
- **[SmartGalleryAI](https://github.com/StarrySea1412/SmartGalleryAI)** — 本地图片管理与 OCR 全文搜索 MVP，包含扫描去重、缩略图生成与分析状态管理。
