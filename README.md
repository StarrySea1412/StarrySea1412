# StarrySea1412

写两类东西：**浏览器里的交互式学习站**，和**本地优先的 AI 工具**（数据不出本机）。

## 交互式学习平台

全程浏览器内运行，全部开源。

- [AI 学习平台](https://github.com/StarrySea1412/ai-learning-platform) — 从 Transformer 到 LLM / Agent / MCP / RAG，每个概念配可交互演示
- [容器学习平台](https://github.com/StarrySea1412/container-learning-platform) — Docker 正课 + K8s 进阶 + 原理篇，自研浏览器内容器沙盒
- [Git 学习平台](https://github.com/StarrySea1412/git-learning-platform) — 动画演示、实战练习、合并冲突模拟
- [Python](https://gitee.com/starry-sea-1412/python-learning) / [Linux](https://gitee.com/starry-sea-1412/linux-learning-platform) / [摄影](https://gitee.com/starry-sea-1412/photography-learning) — 同系列，托管在 Gitee

## 本地优先工具

- [Hermes Watch](https://github.com/StarrySea1412/hermes-watch) — AI 服务器巡检平台：规则引擎为主，LLM 只负责转述
- [Hermes Agent Workbench](https://github.com/StarrySea1412/hermes-agent-workbench) — Agent 工作台：审批门控的工具调用、可回滚写入、长期记忆
- [SmartGalleryAI](https://github.com/StarrySea1412/SmartGalleryAI) — 智能图库：OCR + 语义搜索，把图片整理成可检索的个人视觉知识库
- [ProjectPilot](https://github.com/StarrySea1412/utools-project-pilot) — uTools 插件形态的项目管理领航台
- [ClipMaster](https://github.com/StarrySea1412/clipmaster) — 剪贴板管理器：历史、搜索、分类
